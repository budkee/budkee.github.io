# Projeto Full Stack | Full Stack Project

Este projeto foi criado com o objetivo de estudar as tecnologias que envolvem o desenvolvimento full stack. Para guiar o caminho, foi escolhido o projeto [roadmap.sh](https://roadmap.sh/full-stack) que mapeia a jornada de conhecimento básico das tecnologias mais utilizadas atualmente. Assim, podemos dividir os estudos em Full Stack nos seguintes subareas:

## Interface e Frameworks| Front-End

[] [HTML](https://siriusb.notion.site/HTML-881caa9a94ab474da9da6453eadd0b24), [CSS](https://siriusb.notion.site/CSS-029e24d0c3634b6ab50a0f340690ec20) e [JavaScript](https://siriusb.notion.site/JavaScript-16431d344f9141769f46ba66402233e5)
[] Tailwind
[] Node Pack Manager (npm)
[] React

## Banco de Dados e Comunicação com o Servidor | Back-End

[] Node.js
[] PostgreSQL
[] RESTful APIs
[] JWT Auth
[] Redis

## Manutenção e Monitoramento do App | DevOps

[] Linux
[] AWS Services
[] Monit
[] GitHub Actions
[] Ansible
[] Terraform
