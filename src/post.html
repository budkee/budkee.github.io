--- layout: post title: "Página de exemplo do layout de post" date: 2026-08-16 tags: [exemplo, layout] excerpt: "Página de referência para validar o layout padrão de posts do blog." image: images/pic11.jpg --- ## Objetivo Esta página existe para demonstrar o layout padrão aplicado aos posts do blog. ## Estrutura recomendada - Introdução curta com contexto - Desenvolvimento com subtítulos claros - Conclusão com próximos passos ## Elementos visuais padronizados O layout exibe automaticamente: - Cabeçalho e menu compartilhados com o site - Título, data e tags no topo do post - Imagem principal (quando definida no front matter) - Rodapé padrão com redes sociais ## Conclusão Use este arquivo apenas como referência visual. Para conteúdo real, prefira criar arquivos em _drafts e publicar em _posts.
